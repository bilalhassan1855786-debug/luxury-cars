# Luxury Cars --- Modern Automotive Website

A premium automotive website designed to showcase luxury vehicles
through a modern, visually engaging, and responsive interface.

## 🚀 Live Demo

https://luxury-cars-eight.vercel.app/

## ✨ Features

-   Premium luxury-car themed UI
-   Modern hero section
-   Luxury vehicle showcase
-   Featured cars section
-   Car cards with images and pricing
-   Individual car detail pages
-   Responsive design
-   Modern navigation
-   Interactive hover effects
-   Clean and user-friendly layout

## 🚘 Featured Vehicles

The project includes a collection of premium vehicles such as:

-   Lamborghini Aventador
-   Ferrari SF90
-   Rolls Royce Phantom
-   Bugatti Chiron
-   BMW i8
-   Audi R8
-   Mercedes AMG GT
-   Porsche 911
-   Tesla Model S Plaid
-   McLaren 720S

## 🛠️ Technologies Used

-   Next.js
-   TypeScript
-   Tailwind CSS
-   Responsive Web Design

## 🎯 Project Goal

The goal was to create a premium automotive website that combines modern
UI/UX principles with responsive frontend development and a strong
visual identity.
